# Yacht-Spa

Адаптивный сайт для продажи яхт с интерактивным календарем, мультиязычностью и фильтрацией.

## 🚀 Live Demo
[https://yacht-spa-netlify.netlify.app/](https://yacht-spa-netlify.netlify.app/)

## 🛠 Стек технологий
- HTML5, CSS3, SCSS
- JavaScript (ES6+)
- Gulp (сборка, минификация, BrowserSync)
- Git, GitHub
- Деплой: Netlify
