# Yacht-Spa

Адаптивный сайт для продажи яхт с интерактивным календарем, мультиязычностью и фильтрацией.

## 🚀 Live Demo
[https://yacht-spa-netlify.netlify.app/](https://yacht-spa-netlify.netlify.app/)

## 🛠 Стек технологий
- HTML5, CSS3, SCSS
- JavaScript (ES6+)
- Gulp (сборка, минификация, BrowserSync)
- Git, GitHub
- Деплой: Netlify

## 📦 Как запустить локально
1. Клонируйте репозиторий: `git clone https://github.com/Olesiaaaaaa/yacht-spa.git`
2. Установите зависимости: `npm install`
3. Запустите сервер разработки: `gulp` (или ваша команда для запуска)
